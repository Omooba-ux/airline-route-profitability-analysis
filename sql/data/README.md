# Dataset

This project was developed using a flight-level airline route profitability dataset containing 7,974 records.

The dataset includes information on:

- Routes and destinations
- Aircraft type and capacity
- Passenger volume and load factor
- Demand level
- Revenue components
- Operating cost components
- Profit and profit margin
- Seasonality

During data preparation, 792 missing financial values were investigated and reconstructed where supported by the underlying accounting relationships.

The cleaned dataset was then used for analysis in MySQL and Power BI.

## Data Availability

The dataset is not currently included in this repository.

Before redistributing the original or cleaned dataset, the licensing and redistribution terms of the source dataset should be confirmed.
