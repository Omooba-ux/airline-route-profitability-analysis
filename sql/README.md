# SQL Analysis

This folder contains the SQL queries used to analyze the cleaned airline route profitability dataset in MySQL.

The analysis covers:

- Overall financial and operational performance
- Route profitability and profit margins
- Route category performance
- Demand and load factor analysis
- Operating cost structure
- Aircraft profitability and fleet allocation
- Seasonal performance
- Loss-making flights and routes
- Ancillary revenue contribution

The queries were developed to answer the business questions documented in the main project README.
